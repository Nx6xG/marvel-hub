# Marvel Hub — Das Archiv aller Marvel-Universen

Fan-Projekt: Wiki über 108 Marvel-Filme & -Serien (MCU, Fox/X-Men, Sony, Klassiker, TV-Ära),
128 Charaktere mit Beziehungs-Netzen, Teams, Artefakte, Storyline-Pfade, Post-Credit-Kette,
In-Universe-Chronik, Offene-Fäden-Tracker und Doomsday-Event-Hub mit Countdown.

- `index.html` — die komplette Seite (self-contained, keine Abhängigkeiten)
- `build/` — Build-Pipeline: `python3 build.py` fügt Templates + Daten + Poster zusammen

Poster/Bilder: Wikipedia (Fair Use, verkleinerte Thumbnails). Kein offizielles Marvel-Angebot.
